# Qwen3-0.6B FP32 ONNX (L256) — 获取与校验

> 日期：2026-09-30
> 上游：[开发计划.md](../../../docs/llm-deploy-v1.0/开发计划.md) · [W1-探测方案.md](../../../docs/llm-deploy-v1.0/W1/W1-探测方案.md)

本目录提交的是**模型清单**——`README.txt`、`verification.json`、`LICENSE` 三个小文件，
**不含权重本身**。

权重解压后 2.41 GB（`model.onnx` 25 MB + 三个 `weights-*.data` 共 2.38 GB），压缩包 1.2 GB。
两条入库路径都不通，所以走 Release 资产：

- Git 普通入库：单文件超 GitHub 100 MB 硬上限；
- Git LFS：免费额度 1 GB 存储 / 1 GB/月带宽，2.38 GB 超存储额度约 2.4 倍，
  且 LFS 对象推上去后基本撤不回来（删 commit 不回收，需联系 GitHub 支持）。

Release 资产单文件上限 2 GiB，压缩包 1.2 GB 装得下，也不占 LFS 额度。

## 获取

```bash
# tag: qwen3-0.6b-onnx-l256
gh release download qwen3-0.6b-onnx-l256 --pattern '*.zip'
# 或直接下载
# https://github.com/ScratchV-Compiler/ScratchV/releases/download/qwen3-0.6b-onnx-l256/Qwen3-0.6B-FP32-ONNX-L256.zip
```

解压到本目录的**上一级**，保持 `qwen3-0.6b-onnx/` 目录名和四个文件名不变——
`model.onnx` 用相对路径引用三个 `.data` 文件，改名或拆开存放都会加载失败：

```bash
unzip Qwen3-0.6B-FP32-ONNX-L256.zip -d models/graph/
```

## 校验

`verification.json` 里带解压后每个文件的 SHA-256，逐一比对（分块读，别整文件读进内存）：

```bash
python3 - <<'PY'
import json, hashlib, os
os.chdir('models/graph/qwen3-0.6b-onnx')
v = json.load(open('verification.json'))
for f in v['files']:
    h = hashlib.sha256()
    with open(f['name'], 'rb') as fh:
        for b in iter(lambda: fh.read(1 << 20), b''):
            h.update(b)
    ok = h.hexdigest() == f['sha256'] and os.path.getsize(f['name']) == f['bytes']
    print('OK  ' if ok else 'FAIL', f['name'])
PY
```

## 注意

`README.txt` 明确说明本包内是**真实模型文件而非 LFS 指针**，使用方无需安装 Git LFS——
