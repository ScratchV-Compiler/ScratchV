# W1 两层探测报告与参考用例修复

基线：PR #91 合并提交 `3bb88e81498d6d9293aed70e25a4e5a2104465d0`。本次只包含 W1 两层探测报告、源码/环境归属以及三个固定 ORT 环境的参考用例修复。W2 的完整解析、运行时和后端扩展独立交付。

## 修改

- 两层 IR/QEMU 报告先保存 Markdown/HTML，最后原子发布 JSON。写入、关闭或替换失败时返回失败，尽力留下 FAIL 证据，保留原始数值/执行错误，避免残留成功 JSON。
- 没有本目录 `.git` 的源码副本不向父目录借用 Git 身份。报告保留源码 SHA256，QEMU 对照分别记录当前执行环境和原导出环境。
- 固定 ORT 1.22.1 没有 DOUBLE Cos CPU 内核，且省略 axes 的 ReduceMean + noop=1 路径有内核限制。这三个用例使用 ONNX 官方 ReferenceEvaluator，仍执行生产 parser/IR；其余用例继续 ORT 对照。没有跳过用例、宽泛捕获数值错误或放宽门槛。
- 增加失败注入、源码副本、当前环境归属及原错误保留测试。
