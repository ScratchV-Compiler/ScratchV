## Linux 问题与修复

初次回归为 **971 passed、25 failed、4 skipped**。实际 guest 已完成并转储输出，但 Linux QEMU 在 `quit` 时先断开连接，原运行器将其误判为失败。[QMP 官方说明](https://www.qemu.org/docs/master/interop/qemu-qmp-ref.html#command-quit)允许退出时缺少回复。提交 `01aff1d` 仅接纳完整发送无参数 `quit` 后的 EOF/reset；普通命令断连、发送失败、协议错误、超时仍失败，且继续要求进程退出 0、输出有效、权重校验与清理成功。

首次 W3 完整尝试因启动器解析 Python 软链接而离开虚拟环境，worker 使用系统 Python、缺少依赖，完整 IR 未执行。提交 `cf0f7d3` 保留选定的虚拟环境解释器路径，增加真实软链接虚拟环境回归；没有修改模型算术。
