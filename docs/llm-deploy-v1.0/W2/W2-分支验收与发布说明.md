正式复现环境为 Ubuntu 24.04 x86_64 / Bash / Python 3.12。环境与工具准备见 [Linux 复现约定](../LINUX_REPRODUCTION.md)，七项统一入口和实际 CI 链接见 [W2 README](README.md)。

## 交付范围

- 固定完整 28 层 ONNX 的结构、前端解析、IR verifier、逐节点和真实权重绑定审计。
- RMSNorm/RoPE/SwiGLU/GQA 前端模式；七类基础后端的 16 小图、32 次 QEMU。
- 官方 Tokenizer、输入/mask、最后有效位置 greedy/停止条件，以及完整词表两层随机小配置的单步模型集成。
- 七项统一验收、完整前端 PR 必跑任务，以及拒绝失败、取消、跳过和缺失的 CI 汇总。
- 标量 IR 常量外部绑定一致性；保存日志失败时保留主错误；Linux 取消时清理独立编译器/QEMU 会话。

## 复现与限制

运行统一入口时每次使用不存在的新输出目录。保留 Linux 版本、CPU、依赖和工具版本、源文件哈希、模型/ELF 身份、原始命令、误差及仿真墙钟；七项完整通过才能记为 PASS。新的提交需要新的实际运行证据。

完整图解析不等于完整 0.6B 的 IR/QEMU 数值前向。当前 Attention 使用已定义语义的基础算子组合；完整词表单步模型使用随机小配置，不具备预训练模型语言能力。第二人独立复现和团队接口确认仍由参与者完成；完整权重装载、生成循环等后续阶段不能由本分支的小模型结果代替。
