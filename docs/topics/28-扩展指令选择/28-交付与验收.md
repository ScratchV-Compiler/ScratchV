## 验收方法

在已安装项目和测试依赖的 Python 环境中运行，PATH 需包含支持 RISC-V 的 Clang、LLD、qemu-riscv32；全量回归还需 readelf。

```bash
SCRATCHV_REQUIRE_RISCV_EXECUTION=1 python -m pytest -q tests/test_topic28_acceptance.py
SCRATCHV_REQUIRE_RISCV_EXECUTION=1 python -m pytest -q tests benchmarks/test_benchmark.py
```

验收入口为 99 项：四个交付 DSL 程序；整数商/余数、除零和溢出；DSL/ONNX 标量数学；F-only、D 上 f32、D 上 f64；f64 访存及六种比较的两条分支。结果以实际 ELF 返回的位模式为准，并检查 fflags、调用后的 sp/ra、GPR/FPR callee-saved 状态和 f32 NaN-boxing。

与算子、类型、合法汇编和调用正确性有关的回归保留，完整回归检查共享编译管线兼容性。
