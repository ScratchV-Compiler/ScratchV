## 1. 开发目标与阶段回顾

本课题将原有的“汇编文本 -> 临时混合字典 -> 简易输出”重构改造为生产级、带版本、类型安全的指令计数与对比分析系统：

```text
共享汇编解析 (_asm_parser)
  -> 9大主分类注册表 (OpcodeInfo)
  -> 深度只读统计模型 (InstructionStats)
  -> 多文件基准对比模型 (ComparisonResult)
  -> 多格式报表渲染器 (Text / JSON / Markdown / HTML / Chart)
  -> CLI 工具 & CompilerDriver 集成 & CI 门禁
```

## 3. 详细实施步骤与技术要点

### 3.1 P1：汇编解析层优化（`_asm_parser.py`）
1. 在 `parse_line` 入口强制执行 `clean = line.rstrip("\r\n")`，阻断跨平台 Windows CRLF 导致的正则匹配失败；
2. 识别并归一 `.cfi_*` 和无点号前缀的 `cfi_*` 指示符，标记 `is_directive=True`；
3. `inst_counter.py` 内部废弃旧版私有正则表达式 `_INST_RE`，完全复用共享解析器。

### 3.2 P2：指令分类注册表（`OpcodeInfo`）
1. 注册表使用统一小写 canonical mnemonic 为键；
2. 完整收录 RV32/64IM、F、D、A、C、Zbb、System 扩展指令与通用伪指令；
3. **原子后缀匹配算法**：
   ```python
   _ATOMIC_SUFFIX_RE = re.compile(r'^(amo\w+\.[wd]|(?:lr|sc)\.[wd])\.(?:aqrl|aq|rl)$')
   ```
   仅对原子指令剥离 `.aq/.rl/.aqrl` 后缀，保留浮点（`.s/.d`）与压缩（`c.*`）的原有点号，未命中者兜底至 `MISC`。

### 3.3 P3：数据模型与不变式守恒（`InstructionStats`）
1. `frozen=True` 配合 `MappingProxyType` 确保字典只读；
2. 构造时校验不变式：
   ```python
   assert self.total == sum(self.category_counts.values())
   assert self.total == sum(self.opcode_counts.values())
   assert all(v >= 0 for v in self.category_counts.values())
   assert set(self.unknown_opcodes.keys()).issubset(self.opcode_counts.keys())
   ```
3. 提供 `to_dict()` 与 `from_dict()` 保证严格 JSON Schema 序列化；
4. 提供 `_stats_to_legacy_dict()` 适配器，保留 `_detailed` 键供旧版 benchmark 使用。

### 3.4 P4：多文件比较与消歧（`ComparisonResult`）
1. 提取所有输入文件的指令并集；
2. 基线文件自身的 Delta 统一显式置为 0（`absolute=0, percent=0.0`）；
3. **除零保护**：
   - `baseline == 0 且 current == 0` -> `0.0%`；
   - `baseline == 0 且 current > 0` -> `None`（呈现为 `N/A`，JSON 呈现为 `null`）；
4. **同名文件消歧**：通过 `_make_unique_labels()` 自动为重复的文件名分配 `#1`、`#2` 后缀，避免字典覆盖；
5. 校验 `schema_version`、`classification_version`、`count_mode`、`isa` 一致性。

### 3.5 P5：统一报表渲染
1. `render_text()`：终端整洁表格，支持 `--verbose` 显示详细操作码分布及未知指令告警；
2. `render_json()`：纯净 JSON，严格符合 Single / Comparison Schema；
3. `render_markdown()`：GitHub 表格，自动转义标签内管道符 `\|`；
4. `render_html()`：自包含样式单文件 HTML，**所有外部文本强制执行 `html.escape`**；
5. `render_chart()`：Matplotlib 懒加载，支持单文件柱状/饼图与多文件对比分组柱状图；零指令时优雅绘制提示文字，杜绝崩溃。

### 3.6 P6：CLI 执行流程与严格退出码
- 0：执行成功；
- 1：参数或 I/O 错误（如单文件传 `--compare`、多文件未传 `--compare` 却请求单个报告文件、`--baseline` 不存在）；
- 2：启用 `--fail-on-unknown` 且存在未识别指令（所有请求报告写出后才退出）；
- 3：依赖缺失或文件写出失败。

### 3.7 P7：编译器流水线集成（`CompilerDriver`）
1. 拦截检查：`self.config.backend == "llvm" and self.config.count_instr` 时在编译前直接报错返回；
2. 时序控制：统计逻辑必须置于 `_run_asm_passes` 之后，直接针对最终汇编文本调用 `analyze_instructions(asm_text)`；
3. 统计结果存入 `CompileResult.stats["instruction_count"]`，彻底移除旧版将统计信息塞入 `warnings` 的行为；
4. CLI 入口 `scratchv/main.py` 识别 `instruction_count` 并统一输出终端表格。

## 4. 仿真器接口预留指引（后续扩展）

为了支持运行时动态指令统计（Dynamic Instruction Count）与静态代码的综合比对，仿真器接入时遵循以下契约：

```python
def from_emulator_counts(
    opcode_counts: Mapping[str, int],
    *,
    source: str = "emulator",
    isa: str = "rv32im",
) -> InstructionStats:
    """仿真器动态执行统计工厂方法。"""
    cat_counts = {cat: 0 for cat in _CATEGORY_ORDER}
    unknown_opcodes = {}
    total = sum(opcode_counts.values())

    for op, cnt in opcode_counts.items():
        info = classify_opcode(op)
        cat_counts[info.category] += cnt
        if info.category == "MISC":
            unknown_opcodes[op] = cnt

    return InstructionStats(
        category_counts=cat_counts,
        opcode_counts=dict(opcode_counts),
        unknown_opcodes=unknown_opcodes,
        total=total,
        source=source,
        count_mode="dynamic",  # 区分静态 textual
        isa=isa,
    )
```

- **静态 vs 动态综合对比**：
  直接复用 `compare_stats([("Static (Text)", static_stats), ("Dynamic (Emu)", dynamic_stats)])`，即可生成优化收益与执行热点比对表。
