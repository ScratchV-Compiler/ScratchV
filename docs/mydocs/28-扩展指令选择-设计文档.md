## 1. 概述

### 1.1 目标

在 `ExtendedInstructionSelector` 中完善所有常用算子的指令选择，包括 div/rem/mod、sqrt、min/max、abs 以及 float64 全路径支持，做到类型驱动的精确指令选择。

### 1.2 范围

| 操作 | 说明 | 状态 |
|------|------|------|
| **div (浮点除)** | f32/f64 除法 | ✅ 已实现 |
| **idiv (整数除)** | i32 有符号除法 | ✅ 已实现 |
| **rem (整数取余)** | i32 有符号取余 | ✅ 已实现 |
| **mod (取余别名)** | 同 rem | ✅ 已实现 |
| **sqrt (平方根)** | f32/f64，硬件或库调用 | ✅ 已实现 |
| **min/max** | i32/f32/f64 全类型 | ✅ 已实现 |
| **abs (绝对值)** | i32/f32/f64 全类型 | ✅ 已实现 |
| **float64 全路径** | f64 加载/存储/算术/比较/转换 | ✅ 已实现 |
| **transpose** | 数据布局操作 (no-op) | ✅ 已实现 |
| **concat** | 缓冲区合并 (no-op) | ✅ 已实现 |

### 1.3 当前状态

经过代码分析，原始指令选择存在以下问题：

| 问题 | 严重程度 | 说明 |
|------|---------|------|
| **OpCode 缺失 sqrt/min/max/abs** | 高 | `OpCode` 枚举中没有这些值，handler 已写但无法 dispatch |
| **f32 除法无专用指令** | 高 | `_select_div` 对 f32 走基类 `DIV`（整数除），未使用 `FDIV_S` |
| **OpCode 缺失 rem/mod/idiv** | 高 | 已修复 |
| **transpose/concat 无 handler** | 中 | 有 OpCode 但无 dispatch 方法 |
| **f32 abs/neg 无专用指令** | 中 | 已有 `FABS_S`/`FNEG_S` MachineOp 但未使用 |
| **除零处理缺失** | 中 | 无除零检测或陷阱指令 |

## 2. 架构设计

### 2.1 整体数据流

```
 DSL/ONNX 前端                IR (OpCode)              指令选择                     MachineOp
 ──────────────              ────────────             ────────────                ──────────

 a / b  ──────►  OpCode.DIV ("div")  ──►  _select_div()  ──┬─ f64  ──► FDIV_D
                                                            ├─ f32  ──► FDIV_S
                                                            ├─ i32  ──► DIV
                                                            └─ i64  ──► DIV

 a // b ──────►  OpCode.IDIV ("idiv") ──► _select_idiv() ──► DIV

 a % b  ──────►  OpCode.REM ("rem")   ──► _select_rem()   ──► REM

 a % b  ──────►  OpCode.MOD ("mod")   ──► _select_mod()   ──► REM  (别名)

 sqrt(x) ────►  OpCode.SQRT ("sqrt") ──► _select_sqrt() ──┬─ hw  ──► FSQRT_S / FSQRT_D
                                                          └─ lib ──► CALL sqrtf / sqrt

 min(a,b) ───►  OpCode.MIN ("min")   ──► _select_min()  ──┬─ f64  ──► FMIN_D
                                                          ├─ f32  ──► FMIN_S
                                                          └─ i32  ──► SLT/SUB/AND/ADD

 max(a,b) ───►  OpCode.MAX ("max")   ──► _select_max()  ──┬─ f64  ──► FMAX_D
                                                          ├─ f32  ──► FMAX_S
                                                          └─ i32  ──► MAX pseudo

 abs(x)  ────►  OpCode.ABS ("abs")   ──► _select_abs()  ──┬─ f64  ──► FABS_D
                                                          ├─ f32  ──► FABS_S
                                                          └─ i32  ──► SRAI/XOR/SUB

 transpose ──►  OpCode.TRANSPOSE     ──► _select_transpose() ──► MV (no-op)

 concat   ───►  OpCode.CONCAT        ──► _select_concat()    ──► MV (no-op)
```

### 2.2 类型驱动的指令选择矩阵

```
              OpCode.DIV   OpCode.IDIV  OpCode.REM/MOD  OpCode.SQRT  OpCode.MIN  OpCode.MAX  OpCode.ABS
              ─────────   ───────────  ──────────────  ───────────  ──────────  ──────────  ──────────
dtype=f32  →  FDIV_S       DIV          REM              FSQRT_S      FMIN_S      FMAX_S      FABS_S
dtype=f64  →  FDIV_D       DIV          REM              FSQRT_D      FMIN_D      FMAX_D      FABS_D
dtype=i32  →  DIV           DIV          REM              —            SLT+...     MAX pseudo  SRAI+XOR+SUB
dtype=i64  →  DIV           DIV          REM              —            SLT+...     MAX pseudo  SRAI+XOR+SUB
```

### 2.3 OpCode 扩展

在 `scratchv/ir/types.py` 的 `OpCode` 枚举中新增：

```python
class OpCode(enum.Enum):
    # ... 现有 opcode 保持不变 ...
    DIV = "div"        # 已有
    IDIV = "idiv"      # 整数除法 (truncated toward zero)
    REM = "rem"        # 整数取余
    MOD = "mod"        # 取余别名
    SQRT = "sqrt"      # 平方根
    MIN = "min"        # 最小值
    MAX = "max"        # 最大值
    ABS = "abs"        # 绝对值
```

| MachineOp | RISC-V 指令 | 用途 | 状态 |
|-----------|-----------|------|------|
| `DIV` | `div rd, rs1, rs2` | 有符号整数除法 (M 扩展) | 已有 |
| `REM` | `rem rd, rs1, rs2` | 有符号整数取余 (M 扩展) | 已有 |
| `FDIV_S` | `fdiv.s rd, rs1, rs2` | 单精度浮点除法 (F 扩展) | 已有 |
| `FDIV_D` | `fdiv.d rd, rs1, rs2` | 双精度浮点除法 (D 扩展) | 已有 |
| `FSQRT_S` | `fsqrt.s rd, rs1` | 单精度平方根 (F 扩展) | 已有 |
| `FSQRT_D` | `fsqrt.d rd, rs1` | 双精度平方根 (D 扩展) | 已有 |
| `FMIN_S` / `FMIN_D` | `fmin.s` / `fmin.d` | 浮点最小值 | 已有 |
| `FMAX_S` / `FMAX_D` | `fmax.s` / `fmax.d` | 浮点最大值 | 已有 |
| `FABS_S` / `FABS_D` | `fabs.s` / `fabs.d` | 浮点绝对值 | 已有 |
| `FNEG_S` / `FNEG_D` | `fneg.s` / `fneg.d` | 浮点取反 | 已有 |

### 2.5 类层次与 dispatch 设计

```
InstructionSelector (基类)
  ├── _select_instruction(instr)    # getattr(self, f"_select_{instr.opcode.value}")
  ├── _select_div(instr)            # 基类: 无条件 emit MachineOp.DIV
  ├── _select_transpose(instr)      # 基类: MV (no-op)
  ├── _select_concat(instr)         # 基类: MV (no-op)
  └── ...
       │
       ▼ 继承
ExtendedInstructionSelector (扩展类)
  ├── _select_instruction(instr)    # 追踪 _current_dtype, 然后 super()
  ├── _select_div(instr)            # 重写: 按 dtype 三分支
  │     ├── f64 → _select_fdiv_d()
  │     ├── f32 → FDIV_S
  │     └── i32/i64 → DIV
  ├── _select_idiv(instr)           # 新增: i32 整数除 → DIV
  ├── _select_rem(instr)            # 新增: 整数取余 → REM
  ├── _select_mod(instr)            # 新增: 委托 _select_rem
  ├── _select_sqrt(instr)           # 新增: hw fsqrt 或 lib call
  ├── _select_min(instr)            # 新增: f32/f64/i32 三分支
  ├── _select_max(instr)            # 新增: f32/f64/i32 三分支
  ├── _select_abs(instr)            # 新增: f32/f64/i32 三分支
  ├── _select_neg(instr)            # 重写: f32/f64/i32 三分支
  ├── _select_transpose(instr)      # 重写: MV (no-op)
  ├── _select_concat(instr)         # 重写: MV (no-op)
  └── ... (float64 全路径)
```

### 2.6 除零策略

**选择: 不处理除零，依赖硬件行为。**

理由：
- RISC-V 规范规定 `div`/`rem` 除零时结果写入全 1，不触发异常
- 浮点 `fdiv` 除零产生 ±∞（符合 IEEE 754），不触发异常
- 后续版本可加入可选除零检测（`BEQZ` 检查除数 → 跳转 trap handler）

## 4. sqrt 实现方案

### 4.1 硬件模式 (use_hardware_sqrt=True)

- f32: `fsqrt.s rd, rs1`
- f64: `fsqrt.d rd, rs1`

### 4.2 库调用模式 (use_hardware_sqrt=False, 默认)

```
mv a0, src        # 参数放入 a0
call sqrtf         # 调用 sqrtf (f32) 或 sqrt (f64)
mv dst, a0         # 结果从 a0 取回
```

---

## 5. min/max 实现方案

### 5.1 整数 min (branchless)

```
slt tmp, a, b       # tmp = (a < b) ? 1 : 0
sub diff, b, a      # diff = b - a
and tmp, tmp, diff  # mask = tmp & diff
add dst, a, tmp     # dst = a + mask
```

### 5.2 整数 max

使用基类已有的 `MAX` pseudo-instruction。

### 5.3 浮点 min/max

直接使用 RISC-V F/D 扩展指令: `fmin.s`, `fmax.s`, `fmin.d`, `fmax.d`

---

## 6. abs 实现方案

### 6.1 整数 abs (branchless)

```
srai tmp, x, 31     # 符号位广播
xor tmp2, x, tmp    # 负数时反转位
sub dst, tmp2, tmp  # 负数时加 1
```

### 6.2 浮点 abs

直接使用 RISC-V F/D 扩展指令: `fabs.s`, `fabs.d`

## 7. 风险与限制

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| M 扩展依赖 | 整数 div/rem 需要 RISC-V M 扩展 | 文档说明，在 `-march=rv32im` 下测试 |
| 寄存器分配不支持 F 寄存器 | 浮点指令目标寄存器被当成整数寄存器 | 当前寄存器分配对所有寄存器一视同仁，功能正确但未利用 F 寄存器 |
| sqrt 库调用依赖 | 需要链接 libm (`-lm`) | 文档说明 |
| 常量折叠边界 | `div by 0` 常量折叠需跳过 | 已有 `b != 0` 守卫 |
| OpCode 枚举扩展 | 新增 opcode 可能影响下游 pass | 逐步添加，保持向后兼容 |
