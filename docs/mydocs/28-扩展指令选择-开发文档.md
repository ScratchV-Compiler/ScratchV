## 2. 详细修改步骤

### 2.1 `scratchv/ir/types.py` — OpCode 扩展

**新增 OpCode 值**:

```python
class OpCode(enum.Enum):
    # Arithmetic (binary) — 已有
    ADD = "add"
    SUB = "sub"
    MUL = "mul"
    DIV = "div"
    IDIV = "idiv"    # 整数除法 (truncated toward zero)
    REM = "rem"      # 整数取余
    MOD = "mod"      # 取余别名
    # Arithmetic (unary) — 新增
    SQRT = "sqrt"    # 平方根
    ABS = "abs"      # 绝对值
    # Comparison / selection — 新增
    MIN = "min"      # 最小值
    MAX = "max"      # 最大值
```

同时修改 `is_arith()` 方法，增加 `SQRT`, `ABS`, `MIN`, `MAX`, `NEG`。

### 2.2 `scratchv/backend/machine_types.py` — MachineOp 扩展

新增 `FABS_S` 和 `FNEG_S` 以支持 float32 的 abs/neg 操作。

### 2.3 `scratchv/backend/inst_select_ext.py` — 核心改动

#### 2.3.1 sqrt 指令选择

```python
def _select_sqrt(self, instr: Instruction) -> None:
    """f32: fsqrt.s / f64: fsqrt.d / 或库调用 sqrtf/sqrt"""
    src = self._op(instr, 0)
    dst = self._dst(instr)
    dtype = instr.dest.dtype if instr.dest else DataType.FLOAT32

    if self.use_hardware_sqrt:
        if dtype == DataType.FLOAT64:
            self._emit(MachineOp.SQRT_D, dst, src)
        else:
            self._emit(MachineOp.SQRT_S, dst, src)
    else:
        # Library call: argument in a0, result in a0
        if src and src.kind != "imm":
            self._emit(MachineOp.MV, MachineOperand.reg("a0"), src)
        func = "sqrt" if dtype == DataType.FLOAT64 else "sqrtf"
        self._emit(MachineOp.CALL, comment=func)
        if dst:
            self._emit(MachineOp.MV, dst, MachineOperand.reg("a0"))
```

#### 2.3.2 min/max 指令选择

- **f32**: `FMIN_S` / `FMAX_S`
- **f64**: `FMIN_D` / `FMAX_D`
- **i32**: branchless SLT/SUB/AND/ADD (min) 或 MAX pseudo (max)

#### 2.3.3 abs 指令选择

- **f32**: `FABS_S`
- **f64**: `FABS_D`
- **i32**: branchless SRAI/XOR/SUB

#### 2.3.4 neg 指令选择 (扩展)

- **f32**: `FNEG_S` (新增)
- **f64**: `FNEG_D` (已有)
- **i32**: `sub x0, rs` (基类)

#### 2.3.5 transpose / concat

作为 no-op 实现，使用 `MV` 复制缓冲区指针。

### 2.4 `scratchv/backend/instruction_select.py` — 基类改动

新增 `_select_transpose` 和 `_select_concat` 方法，确保基类也能 dispatch 这两个 OpCode。

### 2.5 `scratchv/backend/asm_emit.py` — 汇编发射

新增 `FABS_S` → `"fabs.s"` 和 `FNEG_S` → `"fneg.s"` 映射。

### 2.6 `scratchv/optimizer/constant_folding.py` — 常量折叠扩展

`_try_fold` 和 `_compute` 增加 `IDIV`, `REM`, `MOD` 支持。

### 2.7 `scratchv/frontend/dsl_parser.py` — DSL 支持

handlers 中新增 `"rem"` 和 `"mod"` 映射。

## 5. 注意事项

| 注意点 | 说明 |
|--------|------|
| **OpCode 新增后 dispatch 自动生效** | 基类 `_select_instruction` 用 `getattr(self, f"_select_{opcode.value}")` 动态 dispatch |
| **rem/mod 同方法** | `_select_mod` 直接委托给 `_select_rem` |
| **sqrt 默认库调用** | `use_hardware_sqrt=False` 默认使用 `sqrtf`/`sqrt` 库函数 |
| **transpose/concat 是 no-op** | 数据布局由内存描述符处理，机器层面仅复制指针 |
| **向后兼容** | 现有 `div` 的 OpCode 值不变，接口不变 |
