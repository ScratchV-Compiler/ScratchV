# 课题28 — 扩展指令选择 测试输入输出

> 每个测试用例的 IR 输入 → dispatch 路径 → MachineOp 输出

## test_div_int32

```
输入 IR:
fun $main()
  .entry:
    $y = div $a $b    ; a:i32, b:i32, dest:y:i32

dispatch: OpCode.DIV → _select_div → _has_int_operand → _select_idiv → DIV

输出 MachineOp:
  .label  # main
  .label  # .entry
  div %y %a %b  # div
```

## test_sqrt_f32

```
输入 IR:
fun $main()
  .entry:
    $y = sqrt $x        ; x:f32, dest:y:f32

dispatch: OpCode.SQRT → _select_sqrt → (lib call) → mv a0,x; call sqrtf; mv y,a0

输出 MachineOp:
  .label  # main
  .label  # .entry
  mv %a0 %x  # sqrt arg -> a0
  call  # sqrtf
  mv %y %a0  # sqrt result
```
